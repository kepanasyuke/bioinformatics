09Команды

Что реально запускается для одного образца.

$ fastp -i S1_R1.fastq.gz -I S1_R2.fastq.gz -o trim/S1.R1.fq.gz -O trim/S1.R2.fq.gz -j trim/S1.fastp.json$ STAR --runThreadN 8 --genomeDir ref/star --readFilesIn align/../trim/S1.R1.fq.gz align/../trim/S1.R2.fq.gz --outFileNamePrefix align/S1.$ multiqc -o qc reports/
Матрица counts и DE синтетические; PCA считается честно, без numpy.
