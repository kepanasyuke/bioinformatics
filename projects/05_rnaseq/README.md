# Проект 05. RNA-Seq: от fastq до QC-отчёта

Проверка чтений до запуска, команды шагов, пороги качества, PCA по матрице counts
и вулкано-график дифференциальной экспрессии. Матрица и DE синтетические,
PCA считается честно — степенным методом на ковариационной матрице, без numpy.

```bash
python projects/05_rnaseq/src/rnaseq.py
```

Отчёт: [docs/report.html](docs/report.html).

## Образцы

| Образец | Группа | Статус |
|---|---|---|
| S1–S4 | control | приняты |
| S5–S8 | case | приняты |
| S9 | case | исключён: нет fastq |

`check_reads` проверяет и наличие файла, и размер: пустой fastq — та же ошибка,
что и отсутствующий.

## Пороги

| Метрика | Хорошо | Предел |
|---|---|---|
| Q30 | ≥ 92% | ≥ 88% |
| дубликаты | ≤ 15% | ≤ 30% |

## Функции

### `list_samples(path)`
Простыми словами: читает таблицу образцов.
Вход: путь к tsv. Выход: список словарей с полями sample, group, r1, r2.

### `check_reads(sample, base)`
Простыми словами: проверяет, что оба fastq на месте и не пустые.
Вход: образец и папка. Выход: список проблем (пустой, если всё хорошо).

### `make_trim_cmd(sample, outdir)`
Простыми словами: собирает команду fastp.
Вход: образец и папка. Выход: список аргументов.

### `make_align_cmd(sample, outdir)`
Простыми словами: собирает команду STAR.
Вход: образец и папка. Выход: список аргументов.

### `run_cmd(command, dry_run)`
Простыми словами: «запускает» команду и возвращает карточку.
Вход: аргументы и флаг. Выход: словарь с командой и кодом.

### `qa_grade(value, good, limit, higher_is_better)`
Простыми словами: ставит оценку ok / warn / bad по двум порогам.
Вход: значение, хороший порог, предельный порог, направление. Выход: строка-оценка.

### `dot(left, right)`
Простыми словами: скалярное произведение двух векторов.

### `matvec(matrix, vector)`
Простыми словами: умножает матрицу на вектор.

### `normalize(vector)`
Простыми словами: приводит вектор к единичной длине.

### `center_rows(matrix)`
Простыми словами: вычитает среднее по каждому гену.

### `covariance(matrix)`
Простыми словами: считает ковариационную матрицу генов.

### `power_iteration(matrix, rounds)`
Простыми словами: находит главный собственный вектор степенным методом.

### `eigenvalue(matrix, vector)` / `deflate(matrix, vector)`
Простыми словами: считают собственное число и убирают найденную компоненту.

### `pca_2d(matrix)`
Простыми словами: проецирует образцы на две первые компоненты.
Вход: матрица образцы × гены. Выход: список точек x, y.

### `demo_counts(seed, size)`
Простыми словами: делает синтетическую матрицу counts с разницей между группами.

### `demo_de(seed, count)`
Простыми словами: делает синтетические результаты DE: log2FC и padj.

### `write_demo(samples_path, reads_dir)`
Простыми словами: создаёт таблицу образцов и файлы-заглушки fastq.

### `accepted(samples)`
Простыми словами: оставляет только образцы с целыми файлами.

### `volcano_points(rows, lfc_cut, padj_cut)`
Простыми словами: делит гены на значимые и нет.
Вход: строки DE и пороги. Выход: точки для графика с группой.

### `heatmap_values(matrix)`
Простыми словами: нормирует экспрессию к диапазону 0..1 для тепловой карты.

### `qc_table(metrics)`
Простыми словами: делает таблицу QC и метки для подсветки.

### `summary_cards(samples, metrics, matrix)` / `sections(...)` / `write_report(...)`
Простыми словами: собирают отчёт.
Вход: образцы, метрики, матрица, DE. Выход: HTML-блоки или путь к файлу.

### `main(argv)`
Простыми словами: точка входа.
Вход: аргументы. Выход: код возврата.

## Что видно на скриншоте

PCA: две группы расходятся по горизонтали, хотя разница в данных — 6 единиц counts.
Volcano: подпись «значимо» отделяет гены с padj < 0.05 и |log2FC| ≥ 1.
Тепловая карта: первые четыре столбца темнее — это control.
