# Changelog

## v2.0 — исправление legacy-пайплайна

### Добавлено
- `set -euo pipefail` (B1).
- `require_var`, `check_exit`, `safe_rm_dir`, `tmp_dir_for` — маленькие функции
  с одним выходом.
- Проверка кодов возврата `bwa` и `samtools` (B9).
- Разбор VCF по полям вместо `grep` (B10).
- Регрессионные тесты Python-части: `tests/test_legacy.py`.

### Изменено
- Перебор fastq через `find -print0` (B2).
- Каталог на каждый образец вместо общего `/tmp/pipe` (B8).
- Вложенность снижена до трёх, `continue` убраны (B4, B6).
- Из `check_vcf` убраны три выхода, остался один (B5).

### Исправлено
- `rm -rf $TMP/` больше не может удалить корень (B7).
- `cd $DIR` без кавычек убран полностью (B3).
