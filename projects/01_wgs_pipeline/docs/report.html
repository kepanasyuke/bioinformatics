06Команды

Режим --dry-run печатает команды и ничего не запускает.

$ python src/wgs_pipeline.py --dry-run[1/5] fastp -i S1.R1.fastq.gz -I S1.R2.fastq.gz -o S1.R1.cl.fq.gz -O S1.R2.cl.fq.gz[2/5] bwa-mem2 mem -t 16 ref.fa S1.R1.cl.fq.gz S1.R2.cl.fq.gz | samtools sort -@ 4 -o S1.sorted.bam[3/5] gatk MarkDuplicates -I S1.sorted.bam -O S1.dedup.bam -M S1.metrics.txt[4/5] gatk HaplotypeCaller -R ref.fa -I S1.dedup.bam -O S1.g.vcf.gz -ERC GVCF[5/5] bcftools filter -i 'QUAL>30 && DP>10' -Oz -o S1.filtered.vcf.gz S1.raw.vcf.gz
Данные синтетические. Пайплайн описан в pipeline/germline.cwl.
