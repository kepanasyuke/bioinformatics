04План действий

Что именно выполнит установщик в режиме --dry-run.

$ ./install_tools.sh --prefix /opt/bio --dry-run[1. bwa-mem2] cd bwa-mem2-2.2.1 ./configure --prefix=/opt/bio[2. htslib] cd htslib-1.20 ./configure --prefix=/opt/bio[3. bcftools] cd bcftools-1.20 ./configure --prefix=/opt/bio[4. samtools] cd samtools-1.20 ./configure --prefix=/opt/bio[5. picard] install -m 0644 picard-3.3.0.jar /opt/bio/share/java printf '#!/bin/sh\nexec java -jar /opt/bio/share/java/picard-3.3.0.jar "$@"\n' > /opt/bio/bin/picard[6. gatk] install -m 0644 gatk-4.6.0.0.jar /opt/bio/share/java printf '#!/bin/sh\nexec java -jar /opt/bio/share/java/gatk-4.6.0.0.jar "$@"\n' > /opt/bio/bin/gatk
Пути и версии условные; структура манифеста и логика сборки рабочие.
